# 使い方

画面は 4 タブ（**検索** / **接続設定** / **フィルタ設定** / **使い方**）。
準備と起動は [../README.MD](../README.MD)、内部の仕組みは [architecture.md](architecture.md)。

## 検索タブ

### 検索する

1. **検索** 欄に型番・図番を入力する
   - 入力するだけで結果が更新される（**ライブ検索**、打ち終わり約 0.28 秒後に 1 回）
   - Enter / **検索** ボタンは即時検索。こちらは対象フォルダを履歴・設定に保存する
   - **×** ボタンで入力と結果をクリア
   - `-` と `_`、半角・全角スペースのゆらぎは自動で吸収される（`REV757_0200` → `REV757-0200`、`AB010 54` → `AB010-85-054`）
   - 画面下の **変換後正規表現** で、意図した形になっているか確認できる
2. **対象フォルダ** を必要に応じて指定する（空欄なら全体検索）
   - `"\\サーバー\共有\フォルダ"` のように **ダブルクォーテーション付き**（自動で付く）
   - 入力欄をクリック／フォーカス／↓キーで **履歴一覧**（最大 20 件）
   - 履歴の右端 **×** … その履歴だけ削除
   - 入力欄横の **×** … 一覧が閉じているときは入力をクリア（＝全体検索）、開いているときは一覧を閉じる
   - **フォルダ選択…** で GUI から選択
   - 履歴から選ぶ／フォルダ選択…／**×** でクリア のいずれでも、**その場で検索し直します**（検索欄に文字を打ったときと同じ）
3. 結果を選んで下部ボタンで操作する

### 結果の操作

| 操作 | 内容 |
|------|------|
| ダブルクリック / Enter / **選択ファイルを開く** | 既定のアプリで開く |
| **選択フォルダを開く** | 親フォルダをエクスプローラーで開く |
| **ファイルコピー** | 選択したファイル／フォルダをクリップボードへ。エクスプローラーで **Ctrl+V** すると実体がコピーされる（複数選択可） |
| **パスのコピー** | フルパスをテキストとしてクリップボードへ（複数は改行区切り） |
| Ctrl+クリック / Shift+クリック | 複数選択（追加 / 範囲） |
| 右クリック | メニュー（ファイルコピー / パスのコピー / 開く / フォルダを開く） |

> ドラッグ＆ドロップは環境によって不安定だったため、いったん外してあります（作り直す予定）。コピーは **ファイルコピー** ボタンまたは右クリックで行ってください。

### 並び替え

列ヘッダ（**種類 / 名前 / 場所 / サイズ / 更新日時**）をクリック。同じ列を再クリックで昇順・降順が切り替わる。

- 初期表示は **更新日時の新しい順**
- 「名前」はファイル名、「場所」はフルパスで並ぶ（大小文字は区別しない）
- 表示は上位 **200 件**まで（フィルタ後が 200 件以下なら全件表示）

### フィルタ（画面下のチップ）

**明るい色 = 表示（除外しない）／暗いグレー = 抑制。**

| チップ | 明るい（初期） | 暗い |
|--------|----------------|------|
| フォルダ / DWG / DXF / PDF / Excel / その他 | その種類を表示 | 非表示 |
| **重複** | 同名ファイルも全部表示 | あいまい同名は **更新日時が最新の 1 件だけ**（ファイルのみ） |
| **旧・OLD** | 「旧」「old」を含むものも表示 | パス・場所・名前に「旧」「old」を含むものを非表示 |
| **システム履歴** | ゴミ箱・FileHistory も表示 | `$RECYCLE.BIN` / `RECYCLER` / `FileHistory` を非表示 |

- **「フィルタ」の文字をクリック** … 表示中のチップをすべて明るい側（全 ON）に戻す
- チップの明暗は保存され、**次回起動時も維持**される
- 重複判定は `-` / `_` / 半角・全角スペースを同一視（`A-B.dwg` と `A_B.dwg` は同名扱い）
- 行の背景色は種類ごとの色（フォルダ＝薄い黄、DWG＝薄い青、DXF＝薄い灰、PDF＝薄い赤、Excel＝薄い緑、その他＝白）。色や対象は **フィルタ設定タブ**で変更できる

### 件数バーの読み方

検索欄の下に、その時の状況が中黒（`·`）区切りで出る。

- `1234 件ヒット` … Everything が返した総数（取得済みと一致）
- `1234 件中 500 件取得` … 総数より取得数が少ない状態
- `重複で 37 件除外` … フィルタごとの除外件数
- `フィルタ後 42 件を全件表示` / `フィルタ後 900 件中 上位 200 件を表示`
- `しばらくお待ちください…` … 追加取得や再検索の実行中（操作は続けられる）
- `すべての種類が非表示` … 種類チップが全部暗く、結果が出ない状態

## 接続設定タブ

Everything が **この PC 以外**で動いているときに使う。

| 項目 | 説明 |
|------|------|
| ホスト / IP | 例: `127.0.0.1`（自分）、他 PC なら `192.168.x.x` |
| ポート | HTTP サーバーのポート（例: `8888`、1〜65535） |
| ユーザー名 / パスワード | Everything 側で認証を設定している場合のみ |

- **設定を保存** … 現在の対象フォルダと一緒に `settings.json` へ書き込む
- **接続テスト** … 実際に問い合わせて疎通を確認
- ホスト／ポート欄をクリックすると **接続履歴**から選べる
- **自身に接続** … この PC の IP を入れてテスト（サーバーが別 PC のときは使わない）

> パスワードは Windows の暗号化機能で保護して保存されます。**暗号化した PC の同じ Windows ユーザーでしか復号できない**ので、別 PC で使うときは一度入れ直してください（[architecture.md](architecture.md) §8）。

ローカル Wi‑Fi / LAN で他 PC の Everything に繋ぐときの注意（ファイアウォール、ゲスト Wi‑Fi、パスが開けない理由など）は  
**[lan-wifi-connection.md](lan-wifi-connection.md)**。

## フィルタ設定タブ

左のリストでフィルタを選び、右で編集する。項目の意味は [architecture.md](architecture.md) §8 の `filters` を参照。

| 項目 | 内容 |
|------|------|
| 表示名 / 色 / 並び（数） | チップと「種類」列の見た目、並び順 |
| 検索画面にチップを表示 | オフにするとチップが消え、そのフィルタは常に「除外しない」側で動く |
| 初期は明るい(表示側) | チップ状態が未保存のときの初期値 |
| 拡張子 | カンマ区切り（例: `.dwg, .dxf`）。`.` は自動補完 |
| キーワード / 照合先 / 大小文字を無視 | パス条件フィルタの判定対象（フルパス・場所・名前） |

| ボタン | 動作 |
|--------|------|
| ↑ / ↓ | 並び順を入れ替え |
| 追加(拡張子) / 追加(条件) | 新しいフィルタを作る |
| 削除 | 選択中のフィルタを削除（`その他` と `重複` は削除不可） |
| この項目を反映 | 編集内容をメモリ上の定義へ反映（保存はまだ） |
| 設定を保存 | `settings.json` へ書き込み、チップと一覧を作り直す |
| 既定に戻す | 出荷時の定義に戻す（確認あり／保存するまでファイルは変わらない） |

## 使い方タブ

アプリ内の簡易ヘルプと、Everything 公式サイトへのリンク（**サイトを開く**）。

## うまく動かないとき

| 症状 | 確認すること |
|------|--------------|
| `検索に失敗しました` と出る | Everything が起動しているか、HTTP サーバーが有効か、ホスト・ポートが合っているか（接続設定タブの **接続テスト**） |
| 0 件になる | 対象フォルダのパスが正しいか。空欄にして全体検索と比べる。種類チップが全部暗くなっていないか |
| 期待する型番が出ない | 変換後正規表現の表示を確認。`旧・OLD` や `重複` が暗くて除外されていないか（「フィルタ」文字クリックで全 ON） |
| 画面が開かない（Python 実行時） | `py -3 -c "import tkinter"` が通るか |
| コピーが失敗する | `pywin32` が入っているか（EXE には同梱済み） |
| 他 PC から接続できない | Everything 側の待受・ファイアウォール・同一 Wi‑Fiか → 詳細は [lan-wifi-connection.md](lan-wifi-connection.md) |
| 接続はできるが開けない／ファイルコピーできない | 結果パスがクライアントから見えるか（UNC 推奨）。同上 |
