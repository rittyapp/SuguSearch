## 優先: セットアップ＋自己更新（実装中）

| # | 項目 | 状態 | 内容 |
|---|------|------|------|
| U1 | setup（どの Windows でも） | **済** | `script\setup.bat` → LocalAppData＋デスクトップ／スタート。Python 不要 |
| U2 | 版管理 | **済** | `version.txt` / タイトルバー表示 |
| U3 | 「更新」タブ | **済** | 更新確認 → ダウンロードして更新／あとで。**GitHub 文言・トークン UI なし** |
| U4 | 差し替え | **済** | staging → previous → current。同じショートカット |
| U5 | 失敗時 | **済（土台）** | `previous\` に直前版を残す |
| U6 | settings 隔離 | **済** | `%LocalAppData%\SuguSearch\data\settings.json` |
| U7 | 配布元を公開 | **済** | Release 公開。利用者はトークン不要（裏で Releases を参照） |
| U8 | 個人パス・開発用語を UI に出さない | **済** | 利用者向け文言のみ |

配置イメージ:

```text
%LocalAppData%\SuguSearch\
  current\SuguSearch.exe
  current\version.txt
  previous\          … 直前版
  staging\           … DL 中
  data\settings.json
  update_runner.bat  … 差し替え用（本体終了後に実行）
```

GitHub: `https://github.com/rittyapp/SuguSearch` の **Releases** に `SuguSearch-<版>.exe` と zip を添付する運用（exe を `SuguSearch.exe` の名前で添付すると 1.0.3 以前の更新処理が失敗するため版付きにする）。

## 見つかった不具合・要対応

| # | 項目 | 状態 | 内容 | すぐサーチ反映 |
|---|------|------|------|----------------|
| A | フィルタ設定レイアウト崩れ | **修正済** | grid＋スクロール | UI 作るとき同趣旨 |
| B | 狭いウィンドウで潰れ | 要確認 | 最低幅など | 同上 |
| C | 色プレビュー追従 | 未着手 | 入力中プレビュー | 同上 |
| D | フィルタ全OFFで0件 | 仕様確認 | 全OFF＝全表示にするか | 種類チップと同論 |
| E | EXE 再ビルド | 運用注意 | setup／Release 前に build_exe2 | — |
| F | フィルタ全ON/OFF トグル | 済 | 「フィルタ」ラベルで切替 | 済（すぐサーチ種類） |
| G | 接続設定「自身に接続」 | **済** | このPCのIPをホストへ入れ、接続して保存まで実行 | 接続UIがあれば同様 |
| H | フィルタで絞っても取得上限に押し出されて結果が出ない | **修正済（1.0.2）** | 種類・パス条件のチップ条件を Everything の検索式に含めてサーバー側で絞る | — |
| I | 対象フォルダ欄の手入力・貼り付けで再検索されない | **修正済（1.0.2）** | 入力・貼り付けでライブ検索、Enter で即時検索 | — |
| J | 接続テストが UI を止める／保存と別ボタン | **修正済（1.0.2）** | 「接続して保存」に統一し非同期化。履歴に接続可否、LAN 探索を追加 | — |
| M | 「更新」タブの更新が必ず失敗する | **修正済（1.0.4）** | ダウンロードした `SuguSearch.exe` を同じ場所へコピーして SameFileError。ダウンロード名を分け、Release の exe も版付きの名前に。失敗時は詳細を表示し `data\update_error.log` に記録 | — |
| N | 「OK」後に新しい版へ切り替わらない（1.0.0 → 1.0.4 で発生） | **対策（1.0.5）・原因未特定** | 差し替え bat 自体と起動方法は実機で動作確認済み。1.0.5 から bat が `data\update_runner.log` に経過を残す。起動は WMI 経由（失敗時はジョブ離脱→従来方式）、EXE 使用中は待って再試行、コピー失敗時は元に戻す | — |
| L | 検索結果の Ctrl+クリックで複数選択できない | **修正済（1.0.3）** | 独自処理と Treeview 標準処理の二重トグル。行上のクリックは標準処理を止める | — |
| K | 狭い幅でチップとボタンが重なる／チップが多いとはみ出す | **修正済（1.0.3）** | 10 個ごとに折り返し、入りきらないときはボタンを上の行へ | — |
