## 優先: セットアップ＋自己更新（実装中）

| # | 項目 | 状態 | 内容 |
|---|------|------|------|
| U1 | setup（どの Windows でも） | **済** | `script\setup.bat` → LocalAppData＋デスクトップ／スタート。Python 不要 |
| U2 | 版管理 | **済** | `version.txt` / タイトルバー表示 |
| U3 | 「更新」タブ | **済** | 更新確認 → ダウンロードして更新／あとで。**GitHub 文言・トークン UI なし** |
| U4 | 差し替え | **済** | staging → previous → current。同じショートカット |
| U5 | 失敗時 | **済（土台）** | `previous\` に直前版を残す |
| U6 | settings 隔離 | **済** | `%LocalAppData%\SuguSearch\data\settings.json` |
| U7 | 配布元を公開 | **済** | Release 公開。利用者はトークン不要（裏で Releases を参照） |
| U8 | 個人パス・開発用語を UI に出さない | **済** | 利用者向け文言のみ |

配置イメージ:

```text
%LocalAppData%\SuguSearch\
  current\SuguSearch.exe
  current\version.txt
  previous\          … 直前版
  staging\           … DL 中
  data\settings.json
  update_runner.bat  … 差し替え用（本体終了後に実行）
```

GitHub: `https://github.com/rittyapp/SuguSearch` の **Releases** に `SuguSearch.exe` または zip を添付する運用。
