## すぐサーチ 1.0.5

アプリの「更新」タブから更新できます。初めて入れる場合は下の **`SuguSearch-Setup-1.0.5.zip`** を展開して `setup.bat` を実行してください（接続先などの設定はそのまま残ります）。

### 直したこと
- 「ダウンロードして更新」の後、新しい版への切り替えが確実に行われるようにしました
  - 切り替え中に古い版がまだ動いていたら少し待ってやり直し、うまくいかなかったときは元の版で起動します
  - 切り替えの経過を記録するようにしました（うまくいかなかったときの調査用）

### 1.0.0 を使っている方へ
1.0.0 の「更新」タブからは新しい版に切り替わらないことがあります。その場合はお手数ですが、一度だけ上の zip の `setup.bat` で入れ直してください。以降は「更新」タブから更新できます。

### これまでの主な変更（1.0.3〜1.0.4）
- 「更新」タブの更新が失敗する問題を修正（1.0.4）
- フィルタで絞ると目的の結果が出ないことがある問題を修正／対象フォルダ欄の手入力でも再検索／Ctrl+クリックの複数選択を修正
- 取得・表示は 500 件、打ち切り時は件数が赤い太字
- 接続設定を「接続して保存」に統一、接続履歴に接続できるかを表示、「LAN内のサーバーを探す」を追加
- フィルタのチップの折り返し、初期ウィンドウの拡大、使い方タブにダウンロード先を常時表示
